- A record's code names it, and a type address names what it is (Blaze, 31 Oct 2026, plan.oracle.search T7; decisions). A private room refuses a code exactly as it refuses the full id: the guard resolves a code to its record's room before it decides, and a code it cannot resolve is refused.
